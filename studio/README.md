# สตูดิโอคลิปรีวิว 10 วินาที (เสียงไทย)

1. `./setup.sh`  ติดตั้งทุกอย่าง (ครั้งเดียวต่อเครื่อง)
2. แก้ `specs/*.json` (ชื่อ รูป บทพากย์ ราคา) แล้วรัน `python3 build.py specs/xxx.json`
   - ภาพตั้งเวลาตามเสียงพากย์ทีละประโยคอัตโนมัติ, ซับไตเติลตรงกับเสียง
   - บทยาวเกินหรือข้อความล้นกรอบ = หยุดพร้อมแจ้งให้ย่อ (ไม่ตัด ไม่เดา)
   - ตัวเลข/อังกฤษแปลงเป็นคำอ่านไทยอัตโนมัติ คำที่ไม่รู้จักให้เพิ่มใน `thai_text.py` (LEXICON)
3. `qa.py` รันอัตโนมัติท้าย build: ความยาว/ขนาด/ความดัง LUFS/พีค/เสียงไม่ถูกตัด/ถอดเสียงกลับ/เฟรมไม่ว่าง + contact sheet
4. `ab.py "ประโยค A" "ประโยค B"` เทียบว่าถ้อยคำไหนเสียงชัดกว่า
แก้ไขซ้ำเร็ว: เสียงแคชต่อประโยค แก้เฉพาะประโยคที่เปลี่ยน
